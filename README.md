# OS_Project_CSE323

SysPulse is a Python-based Linux system monitoring and diagnostic application that provides real-time information about system performance and health.
It monitors CPU, memory, battery, storage, network, security, kernel through a structured terminal dashboard. The application also provides health scoring, automatic diagnosis, historical analysis, and report generation while using caching and concurrent processing for efficient performance.
